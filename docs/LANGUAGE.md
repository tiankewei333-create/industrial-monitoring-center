# Language & documentation policy

## Canonical

- **English** for README, code comments, CI YAML comments, commit messages, and docs under `docs/`.
- Prefer Conventional Commits in English (`feat:`, `fix:`, `docs:`, …).

## UI copy

- English-first strings in the web app.
- Add i18n (e.g. `en` / `zh`) only when product needs localization — keep English as the default catalog.
